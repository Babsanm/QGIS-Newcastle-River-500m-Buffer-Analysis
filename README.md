
# Newcastle River 500 m Buffer Analysis

## Project Overview

This project demonstrates the use of QGIS for environmental spatial analysis
of rivers, streams and sampling locations around Newcastle/Gateshead.

## Objectives

- Map river and stream networks
- Create sampling locations
- Create a 500 m buffer around sampling points
- Identify river and stream sections within the buffer
- Calculate river/stream lengths within the buffer

## Software

- QGIS
- OpenStreetMap data
- QuickOSM

## Spatial Analysis

1. River and stream data were obtained using OpenStreetMap data.
2. Sampling points were created in QGIS.
3. A 500 m buffer was created around sampling locations.
4. Intersection analysis was used to identify waterways within the buffer.
5. River/stream lengths were calculated.

## Skills Demonstrated

- GIS data management
- Coordinate Reference Systems
- Buffer analysis
- Vector intersection
- Spatial analysis
- Environmental mapping
- Attribute-table analysis

## Outputs

The project produces a map showing sampling locations,
500 m buffer zones and river/stream sections within the buffer.
